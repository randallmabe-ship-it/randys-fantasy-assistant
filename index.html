Fantasy analysis built around the leagues I actually play.

Randy's Fantasy Assistant is a personal, non-commercial analytics application designed to evaluate Yahoo Fantasy Football leagues using each league's own settings, scoring system, rosters, matchups and available-player pool.

Planned access model: Yahoo Fantasy Sports API · Read-only · Personal/single-user use

Planned analysis

The project is designed to turn authorized fantasy data into practical decision support without performing transactions on the user's behalf.

League-aware scoring

Analyze league settings and stat modifiers instead of assuming standard fantasy scoring.

Roster analysis

Evaluate roster construction, positional depth, weekly options and schedule context.

Waiver analysis

Identify available players and free agents that fit the needs and scoring rules of each league.

Weekly matchups

Compare teams, schedules and lineup options for upcoming fantasy matchups.

Season & playoffs

Use standings and future schedules to support regular-season and fantasy-playoff planning.

Transaction context

Read league transaction history to understand player movement and roster changes.

Purpose

This is a personal software project intended primarily for the developer/owner's own Yahoo Fantasy Football leagues. It is not a public fantasy platform, gambling product, paid advisory service or automated roster-management service.

The project will keep individual leagues separate so analysis respects each league's unique settings and scoring rules.

Yahoo Fantasy data requested

  • Authenticated user's fantasy leagues and teams
  • League metadata, settings and scoring
  • Team rosters
  • Schedules and matchups
  • Standings
  • League transactions
  • Player metadata, ownership and availability
  • Relevant fantasy statistics and points

Data & privacy

  • The planned integration will use Yahoo OAuth 2.0 authorization.
  • OAuth client secrets, access tokens and refresh tokens will not be exposed in public website source.
  • Yahoo Fantasy data will be used for the owner's private fantasy analysis and will not be sold or redistributed as a standalone dataset.
  • Only the access needed for the intended analysis will be requested.
